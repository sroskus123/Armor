CNPCExtended

v1.2.0 MC 1.20.1 / 1.21.1 Forge 47+ Fabric 1.21.1

Extension framework pro CustomNPCs. Tento web slouží jako jednoduchý návod, jak mod stáhnout, nainstalovat a spustit na klientovi i serveru.

Co mod umí

Sem si napiš hlavní informace o modu. Můžeš zde popsat, co hráč získá po instalaci.

  • HTML GUI — možnost používat vlastní HTML menu ve hře.
  • HUD overlays — vlastní prvky na obrazovce hráče.
  • Client + Server mod — mod je potřeba mít na serveru i u hráče.
  • Custom commands — vlastní příkazy a napojení na scripty.
  • Asset loading — načítání vlastních obrázků, stylů a souborů.

Požadavky

Minecraft

Podporované verze: 1.20.1 / 1.21.1

Loader

Forge 47+ nebo Fabric podle verze modu.

Server

Mod musí být ve složce mods na serveru.

Klient

Každý hráč musí mít mod také ve své složce mods.

Instalace

  1. Stáhni správnou verzi modu podle verze Minecraftu.
  2. Vypni Minecraft i server.
  3. Vlož soubor .jar do složky mods.
  4. Stejný soubor musí mít i hráči na klientovi.
  5. Spusť server a zkontroluj konzoli, zda mod naběhl bez chyby.
Pokud server po instalaci spadne, zkontroluj, zda máš správnou verzi Forge/Fabric a správnou verzi Minecraftu.

FAQ

Musí mít mod i hráči?

Ano. Pokud mod přidává klientské funkce, musí být na serveru i u hráčů.

Funguje to na Forge?

Ano, pokud stáhneš Forge build pro správnou verzi Minecraftu.
